# 匿名单篇读取

单条公开笔记链接优先走本地脚本 `scripts/anonymous-note-resolver.mjs`。它只请求用户提供的这一条链接，使用 `credentials: omit`，不读取或发送 Cookie、Token、Local Storage、浏览器 Profile，也不伪装成登录浏览器。

脚本从小红书公开页面的内嵌状态数据中提取标题、正文、作者、标签、图片 URL 和视频 URL，输出规范化 JSON。图片 OCR、视频字幕/语音和关键帧仍按媒体路由处理；脚本本身不声称已经完成 OCR 或 ASR。

## 路由

- `入口=链接` 或 `入口=链接列表`：逐条尝试匿名解析。
- `入口=收藏` 或 `入口=喜欢`：登录浏览器只用于取得用户明确授权的列表和卡片；取得笔记 ID 后，单篇内容优先切到匿名解析。
- 匿名页面没有笔记主体、返回登录墙、验证码、访问限制或页面结构改变时，标记 `访问受限`、`页面异常` 或 `部分读取`，不要连续重试，也不要自动切换到登录态发请求。
- 只有在用户已授权可见浏览器且确实需要补读时，才把同一链接交给浏览器阅读路径；这属于显式兜底，不是匿名解析器的回退请求。

## 安全边界

- 初始链接只接受 `xhslink.cn` 或小红书页面域名；重定向最多 3 次，并拒绝跳出小红书域名。
- 输出的 `sourceUrl` 去除分享参数和会话参数，只保留可重新打开的笔记地址。
- 页面和媒体响应有大小限制；图片/视频候选只允许小红书 CDN 域名。
- 匿名解析失败即失败。不得加入代理池、UA 轮换、签名逆向、验证码绕过、批量翻页、后台定时任务或 Cookie 回退。

## 可运行验证

```bash
node skills/read-xhs-notes/scripts/anonymous-note-resolver.mjs <公开小红书链接>
```

成功时输出规范化 JSON；失败时输出简短错误并返回非零退出码。真实链接验证应保持低频、单条、只读，并把结果中的标题、正文和媒体 URL 当作待核对证据，不把匿名请求当作平台官方 API。
